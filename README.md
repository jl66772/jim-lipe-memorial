# Jim Lipe Jr. memorial site (DRAFT, not published)

A static site: `index.html`, `assets/`, `media/`. There's no build tooling beyond Python with Pillow and ffmpeg.

## Update with new photos
1. `python3 /workspace/kululu/sync.py`  (pulls new Kululu uploads into the source folder)
2. `python3 build.py`  (processes only new media and regenerates index.html)

## Edit content
- `site.json`: title, name, dates, dedication, featured photo (a file stem from the source folder), and the section list and order.
- Framing (made for James): `site.json` keys `page_title`, `eyebrow`, `title`, `dedication` (her opening note), `photos_title`/`photos_note`/`videos_title`, `footer`/`footer_credit`.
- Sections: each entry has `id`, `title`, `nav` (short menu label), `file`, and `position` (`before` = above Photos, `after` = below Videos). Current order: About Your Dad, Things Your Dad Loved (cards in `content/loved.html`), You & Dad, then Photos and Videos, then Letters & Memories for James and Dad's Celebration of Life.
- `content/*.html`: the HTML for each section. To add a section, create a file and add `{"id","title","file"}` to `sections`. 

## Media processing
Photos become 1600px WebP (lightbox) and 400px square WebP thumbs. Images are re-encoded, so EXIF and GPS data are stripped. GIFs use their first frame.
Videos become H.264 MP4 at 720p, CRF 27, with metadata stripped and a JPG poster frame.

## Features (Oct 2026)
Pages: `index.html` (home), `timeline.html`, `map.html`, all generated by `build.py`. Menu: the main items come from `sections[].nav`, and items marked `"more": true` go in the "More" dropdown.

- **Sections**: each entry in `site.json` → `sections` is either `{"file": "content/x.html"}` or `{"builtin": "potd|photos|videos|memories|letters|playlist"}`. Reorder the list to reorder the page.
- **Photo of the Day**: chosen in the browser from today's local date, so it stays the same all day and changes daily. Tapping it opens the lightbox.
- **Adventure Map** (`map.html`): Leaflet + OpenStreetMap, no key. The pins are only the places in `site.json` → `map_regions` (approximate region centres). Photos are matched to regions at build time using EXIF GPS from the originals and a bounding box. **No photo coordinates are ever written to the site**, and the published WebP files have EXIF stripped. If a region has no photos, it shows a placeholder.
- **Timeline** (`timeline.html`): grouped by EXIF DateTimeOriginal year. Photos with no date, or dated on/after `undated_after` (default 2026-09-26, usually re-photographed prints or screenshots), go under "Undated memories". In `timeline.json`, `move` sets {photo stem: year or "undated"}, `eras` sets {year: label}, and `markers` holds obituary milestones.
- **Letters for Later**: PRIVATE file `/workspace/jim-memorial-letters/letters.json`, outside the repo and never committed. A letter is `{"from", "show_from", "unlock": "YYYY-MM-DD", "label", "text"}`. The text is published only once `unlock` has passed and the site is rebuilt and published (the daily publish handles this). Until then, only a sealed card is shown (label, date, and from-name, or "Someone who loves you" if `show_from` is false). Entries with `"example": true` are never published. Delete the 3 examples when real letters arrive. Back up this file somewhere private, because it is the only copy.
- **Ask Dad's Friends**: approved answers go in `content/memories.json` as `{"prompt", "text", "name"}`. Set `share_memory_url` (e.g., a Google Form) to turn on the "Share a memory" button. "Add your photos" links to `kululu_upload_url`.
- **Playlist**: set `playlist_embed_url` (Spotify: https://open.spotify.com/embed/playlist/ID, YouTube: https://www.youtube.com/embed/videoseries?list=ID). Until then it shows "coming soon".
- **Birthday / remembrance notes**: `birthday` ("MM-DD", empty = off), `remembrance_date` ("09-26"), `*_note`, and `*_photo` (photo stem). The note shows in a banner above the hero on that day. Preview with `?preview=birthday` or `?preview=remembrance`.
- **Ride for Jim**: `content/ride.html`.
